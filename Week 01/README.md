# Week 01 — SQL & Data Loading

Zero to Data Engineer — Week 01. Load a messy social-media dataset into PostgreSQL, then learn SQL by querying it.

## What's here

| File | What it is |
|------|------------|
| `create_tables.sql` | Creates the `raw` schema and all 7 tables with types and foreign keys. Run this first. |
| `tutorial 1.sql` | The SQL walkthrough we cover in class — Sections 0–19 (joins, CTEs, views, window functions, indexing, partitioning, star schema, and more). |
| `Homework Z2D C1 W1.pdf` | This week's assignment. |
| `Dataset/` | The 7 CSV files + a detailed README explaining the data and how to import it. |

## Getting the files (clone the repo)

This is a **private** repo. You must be signed in to the GitHub account that was added to the bootcamp students team.

```bash
git clone https://github.com/zuucrew/dw-fundamentals-bootcamp.git
cd "dw-fundamentals-bootcamp/Week 01"
```

When prompted, log in with your GitHub account (a browser window opens, or paste a Personal Access Token as the password). If you don't have Git installed, get it from https://git-scm.com/downloads.

> Prefer no command line? On the repo page click the green **Code** button → **Download ZIP**, then unzip it.

## How to start

1. Open the [Dataset README](Dataset/README.md) and follow it to load the 7 CSVs into PostgreSQL.
2. Run `create_tables.sql` to set up the schema and tables.
3. Work through `tutorial 1.sql`.
4. Complete `Homework Z2D C1 W1.pdf`.
